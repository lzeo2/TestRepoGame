# Merge Cats Defender Hacked (hacked variant)

Hacked variant of Merge Cats Defender; original by CrimSun (crimSun-dev), https://github.com/crimSun-dev/merge-cats-defender; hacking modifications made for this mirror with permission requested via GitHub issue #1; all rights with original author.

Hacking modifications (cheats): unlimited battle coins (START_COINS 999999, +9999 per drip tick via the game's own drip timer), zero deploy cost on every unit, all 17 cats unlocked from level 1, isolated hacked save slot (`pawdefense.save.hacked.v1`) so the base-game save is untouched. Gameplay, waves, and art are otherwise identical to the vendored base copy.
