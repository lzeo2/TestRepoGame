# Retained host bridge contract

Original adapter API: `createRetainedHostBridge({mode:'factions', config, rosters, onSnapshot})` from `retained-host-bridge.mjs`. `config` is an existing createFleet config; `rosters` is two arrays of retained VehicleKind names. `onSnapshot(playerId, factionSafeSnapshot)` is optional, trusted presentation callback. Non-Factions returns null without side effects. Returned object supplies `beforeStep(room)`, `afterStep(room)` (outcome or null), `allow(room,id,message)`, `reset(room)`, `paused()`, `setPaused(boolean)`, `dispose()`, `snapshot(room,playerId)`, `stats()`.

Host wiring artifact `retained-host-wiring.mjs` exports `applyRetainedHostWiring(relativePath, text)` for exactly `src/sim/combat.ts`, `src/sim/room-engine.ts`, `src/sim/loopback.ts` and `HOST_FILES` list. It adds original code only, hash-pinned to retained candidate, never writes source. Patched LoopbackOptions accepts `hostBridge`, supplies it to RoomEngine, disposes on close. Paused advance is stopped before tick accumulator changes. RoomEngine.handle calls allow before dispatch; beforeStep after syncFleet, afterStep after normal cleanup/updateBots, before native score/match logic; bridge outcomes use native endMatch and reset lifecycle. CombatState has hostFleet.resolveProjectile(p,from,to,maxFraction,damage). Gun-only hook called after native nearest aircraft/ground/ship sweeps and before applying native hits; true consumes round. Damage is existing WEAPONS base * gunRangeFactor * shipScale. Only real accepted projectile array entries acquire provenance from a current occupied authoritative host airframe. Captured owner/vehicle/team/weapon identity remains valid after launcher death/disconnect; mutation, unregistered copies and obsolete CombatState callbacks reject. Reset/disposal clear provenance. No new RAF, fire commands, flight engine or synthetic ammo.

Run `node Games/Wings/authoring/retained-host-bridge-check.mjs` from the repository root (Node 22.23.1). Its loader applies the artifact to the actual tracked TypeScript in memory and executes real RoomEngine/loopback using `stripTypeScriptTypes` with local extensionless resolution, without dependencies. Mechanical fixtures position real spawned vehicles, but positive fire comes through real buffered host input, not manually appended projectiles. The test checks source drift/repeat rejection, ammo/cooldown, sustained fire, damage, friendly/closer-native obstruction, faction restrictions, pause, objective/reset/restart, close disposal and native nonbridge compatibility.

For a permitted local candidate, provide the returned bridge as patched `createLoopbackRoom(..., {hostBridge: bridge})`'s fourth-argument option; `onSnapshot` can feed the existing faction-safe rig consumer. It is **not** automatically installed by GameSession or the lobby. The bridge accepts two human-only teams and three straight-gun IDs; bots reject. Normal/solo/custom calls return null and retain the native path. Missiles, ASW, host AA, generic-fleet suppression, selected-map geography and served view wiring are not implemented by this bounded adapter. Native host clock owns pause and the 15-second reset; FC does not independently auto-reset during host intermission. Empty segments have no replay effect; replay is still capped at 4096 state-changing actions. See the [delivery and withheld deployment gate](../../../docs/wings-host-bridge-delivery.md). No permission, source build or served/native acceptance follows.
