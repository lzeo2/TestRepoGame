# Sunny theme source receipts

Doge Miner ships a local jQuery UI Sunny stylesheet. The files below restore its missing backgrounds and button icons for offline use. Each copy was compared byte for byte with the jQuery UI 1.10.4 release on 26 November 2026. The two previously bundled PNGs are outside this receipt.

The artwork is available from the [versioned Sunny release directory](https://code.jquery.com/ui/1.10.4/themes/sunny/images/). Append the filename to retrieve an individual PNG. jQuery UI provides the [upstream MIT licence](https://raw.githubusercontent.com/jquery/jquery-ui/1.10.4/MIT-LICENSE.txt), distributed in [MIT-LICENSE.txt](MIT-LICENSE.txt).
