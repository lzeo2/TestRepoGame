Word Relay Riot

Pass-and-play word chain for 2–6 players. The next word must start with the last letter of the previous one.

Players

3

Category

Seconds per turn

A valid word scores +1 per letter. −5 for a duplicate, −5 if the timer runs out. Words must be on the bundled category list.

Every player takes 3 turns, then the highest score wins.
