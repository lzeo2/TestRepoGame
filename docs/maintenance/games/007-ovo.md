## Gameplay and controls

Catalog calls this a parkour platformer; exact movement/jump/slide bindings and completion rules require native engine/menu confirmation. Older wiki WASD/Shift claims are not verified here. Modloader `keyDown()` toggles its menu with backtick (192); close restores canvas input via `enableClick(map)`. Settings/Profiles explicitly report unavailable; do not describe them as working. Optional fly/TAS/random-key mods intentionally alter play and are not automatically security exploits. Default backend entries inspected are disabled. Base-level start/restart/touch behavior is engine-owned, not supplied by a new wrapper.

## State and persistence

`modSettings` is parsed repeatedly without guards; migration creates `mods/settings/skins/version`, merges backend defaults and preserves custom mods. Custom scripts are executed as inline script text from the stored `url` field when enabled. This is a deliberate code-capable mod trust boundary. Hooks wrap Construct prototypes and dispatch `LayoutChange`, `CallFunction`, `DialogOpen`, `DialogClose`, `SaveGame`, `ButtonClick`. `SyncStorage` owns base-game save data, with `CurSkin` used directly; its underlying key was not resolved. Menu input disabling records behavior flags and UI dimensions for restoration. `C2_RegisterSW` registers local `sw.js`; registration alone does not establish cache closure.

## Audit findings

- MEDIUM, `src/modloaders/util/ovo.js: enableClick()`: restores `inst.isEnabled`, but `disableClick()` mutates the matching behavior's `isEnabled`. Closing the menu can leave engine buttons disabled. Root fix: restore that same behavior object; test every menu-close caller.
- MEDIUM, `modloader.js: cleanModLoader.init()`: corrupt `modSettings` JSON aborts initialization. Validate schema and recover only this key while retaining backup/export.
- MEDIUM, same initialization skin migration: custom skins are copied into `freshUserConfig['mods']` rather than `skins`. Root fix the destination branch; regression with a custom skin and existing custom mod.
- HIGH evidence hold, `sdk.html` external script and `GameAnalytics.js`: dynamic runtime reachability needs native request capture; do not label every dormant file an active fetch.
- MEDIUM, `util/hooks.js: new Function`: source-string recompilation is brittle and CSP-sensitive, not proof of XSS. Prefer preserving original callable references when approved.
