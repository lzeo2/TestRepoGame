## Audit findings

- **HIGH, save crash risk:** `vex7.min.js`, SaveGame constructor `localStorage.getItem(r.Constants.STORAGE_KEY)`/`JSON.parse(t)`, and `saveProgress`. Corrupt JSON/access denial/quota can interrupt initialization or progression. Root fix: guarded validated restore/write in SaveGame, retaining a backup and unsaved-state feedback.
- **MEDIUM, endless load:** `index.html`, `addScript` sets only `onload`, no `onerror`; either version or game load failure strands the spinner. Add failure handling at the shared helper and a retry status.
- **HIGH, conditional offline boundary:** `gamedistribution/js/main.min.js`, IMA script URL list and `gd__resume__button` CSS URL. Localizing only telemetry is not complete dependency closure. Reproduce SDK activation; replace external ad behavior with approved local inert API semantics, not another remote SDK.
- **MEDIUM, accessibility:** entry zoom disabled; `assets/css/app.css` spinner has no reduced-motion override. Restore shell zoom and readable reduced-motion loading.
- **HIGH, rights hold:** distribution URL does not clear game/asset rights.
