## State and persistence

Banked profile key `slipstream-borough-v1`, canonical schema3,128KiB shared boundary; schema1/2 migrate through descriptor-safe validation preserving old money, ownership, upgrades and purchased kits/finishes, with new counters0 and stripe/spoiler null/false. Fields include cash/owned/selected/upgrades/level/best/reservation/settlement counters/testMode careerDistance/escapes and per-owned-car customizations `{paint,wheels,stripe,spoiler,gadget,gadgets}`. Strict hex finishes and owned mounted-kit identity reject malformed saves; loaded raw bytes remain the original same-read token until a normal save. Runs remain memory-only; reload discards the run and pays nothing. Start must save its reserved profile before simulation, settlement occurs only at the terminal transition. Unknown/accessor fields, invalid values and inconsistent identities reject.

Shared storage loads same-read raw bytes and validates before parsing into the game; compares expected bytes before scoped writes. Denied/corrupt/quota/conflict errors visibly lock writes. Reset is nonblocking native dialog with explicit consent and a pre-dialog token; cancellation preserves bytes. Storage events lock cooperating tabs. No atomicity, ABA, tamper-proof ledger or noncooperating-writer guarantee. The unadvertised owner test path persists all cars/max money; it is never natural progression evidence and is not cryptographically secret.
