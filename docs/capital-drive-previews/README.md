# Capital Drive browser previews

Actual Chromium captures from the 24-check browser integration pass recorded in
[the verification receipt](../verification/capital-drive-2026-11-12.md).
The runtime is the one checked at `4da9963`. These are software WebGL renders,
not concept images or measured N100 hardware performance.

- [Telopea Park School streets](telopea-driving.png): moving pedestrians,
  traffic, estimated architecture and original frontage details.
- [Canberra road map](canberra-map.png): real road geometry and a directed
  route between exploration destinations.

The map data and building outlines have the source credits shown in the game
footer; see [provenance](../capital-drive-sources.md). Facades, heights,
vegetation and street furniture remain approximations.
