## Order and acceptance

1. **Establish defects and completion gaps.** Unchanged full native M2 mobile
   Close remains held. Read-only first-wave workers investigate input, pure
   gameplay/progression/save rules and UI/rendering lifecycle. No blind third
   core workaround, mutated debug state or altered test presented as acceptance.
2. **Repair demonstrated shared roots and finish the approved compact game.**
   Main chooses concrete content/UI contracts after source review, then assigns
   disjoint bounded implementation paths. Preserve turn-based three-member team,
   five elements, eighty supplied original models/colors, current valid saves,
   deterministic encounters and exact pending battle continuity. A real coherent
   ending/learning loop is a completion requirement, not a decorative launch menu.
3. **Verify frozen source independently.** Pure regressions, actual normal-input
   battle/capture/evolution/recovery, saves/denial/corrupt imports, keyboard/touch,
   320/390px inspection single Close, context/model failures and personally
   reviewed real images. Negative fixtures and timing-instrumented variants stay
   labeled. Hardware/rights are not certified from software-rendered screenshots.
4. **Follow-up ten game plans.** Two distinct slots per requested genre. Research
   actual upstream source and code/art/audio/font permissions, local closure and
   size/budget first. Detailed plans precede any ingestion that lacks clearance.
   Collection/heist inspiration uses general mechanics only; no copied Roblox
   characters/memes, assets, code, title, logo, maps, UI or promotional imagery.
   Prefer legitimately ingested games, not ten AI inventions with fabricated
   attribution. No guarantee of ten viable licensed candidates.
5. **Legacy authorship sweep.** Parallel read-only Git/manual/history triage
   distinguishes confirmed ingested, confirmed earlier locally authored,
   current authorized originals and unknown. Missing attribution is not proof
   of AI authorship. Recommend refurbishment or removal with source/value and
   runtime consumer evidence; Main makes final decisions. Protected Character AI
   remains immutable; no audit-only folder deletion or notice erasure.
