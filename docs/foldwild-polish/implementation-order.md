# Foldwild completion implementation order

Main now finalizes the pending choices in [completion contract](completion-contract.md) under the owner's instruction to finish the plan and implement it. This is implementation of the existing authorized original game, not creation/registration/publication of another game. Historical design alternatives remain dated; this order controls this bounded milestone. Native Close, natural campaign, hardware and rights acceptance are not waived.

## Frozen direction

- **F3:** three return lessons at the existing camps in regions 0, 1, 4, in that order, after all five credited regional trials. Travel normally; no teleport or mandatory class/build/collection gate. Existing hosts Maren, Sola, Oren; existing source species only.
- Stage 0, **Maren: Energy on the return trail**, Rootfold Meadow camp: Geodelve level 30, Trellisect level 30. Lesson: conserve energy, shield when threatened, change partners before exhaustion.
- Stage 1, **Sola: Partners on the return trail**, Stillwater Reach camp: Catarill level 32, Velvetorque level 31. Lesson: switch into useful coverage, watch incoming energy and status.
- Stage 2, **Oren: The final field record**, Quietfold Hollow camp: Velvetorque level 35, Aurelvane level 34, Hearthol level 34. Lesson: adapt to disruption and protect the team. This is the campaign climax, not a new species or map.
- Camp still offers ordinary free recovery and at least four kites. Each lesson is explicitly chosen through camp services, with opponent preview and Begin/Back. Starting checks proximity, region, five trials, expected stage, usable team and input phase again. Losing heals/returns to the existing camp, retains completed stages and retries the same stage without cost. No automatic chained fight.
- Winning advances exactly one stage; ordinary encounter XP `12*sum(enemy levels)+20` per existing team member, Marks `18+2*sum(levels)`, score `40+10*sum(levels)`, existing caps. No additional terminal economic payout. Encounter index increments exactly once for resolved win/loss, preserving shop epochs. No capture/flee from lessons.
- Ending: “Your partners brought the route notes home. The trailkeepers add the final pages to the shared field record. All five routes are open. Keep exploring, meet new allies, and complete your own ledger.” Explicit Continue free play; completion persists, collection remains a separate 80-species goal. New run clears completion with the existing exact-byte consent; cancel changes nothing.
- **R1:** after completion, all five existing regional trial locations offer explicit rematches using their original teams/levels. Reuse rival mechanics, forbid capture/flee, apply ordinary encounter rewards on each genuinely won fight, never first-trial payouts/stage credit. Loss uses existing free recovery. No extra opponents, currency, avatars or assets.
- **H/P1:** ranks derive from existing monotone history, without new telemetry or stored rank counters. Rank 0 locked; rank 1 retains existing unlocks. Rank-2/rank-3 thresholds: Pathfinder 3/9 distinct claimed supplies; Binder 10/25 caught species; Warden 3/5 credited trials; Tactician 4/5 caught elements; Quartermaster 3/6 completed contracts. Legacy Iven credit retains its established meaning; no retroactive payout. Free class switching at outposts remains.
- Exact rank-1/2/3 benefits: Pathfinder extra fiber **1/2/3**; Binder capture bonus **0.04/0.06/0.08**; Warden shield bonus **2/3/4**; Tactician incoming switch energy **1/2/3**; Quartermaster delivery bonus Marks **5/7/10**. All class Wait bonuses remain zero. Capture <=0.9, shield <=26, energy <=maximum, inventory <=999, Marks <=1e6. Crossing a threshold uses the pre-transaction rank for that transaction; no second reward.

## Save and module contract

Use **canonical version 3**, accepting genuine v1/v2 saves through migration. Same primary/backup keys. Old progress migrates to unstarted finale, not implicit completion. Older runtimes reject v3 on reload rather than silently projecting away completion. Close/export older tabs before upgrade; noncooperating already-open historical writers remain a disclosed limit of the existing protocol.

New state fields: `finaleStage` integer 0..3 (completed stage count), and `pendingChallenge` null or exact `{kind:'finale'|'rematch',id:integer}`. V3 requires both fields; old versions default to 0/null and must not smuggle nondefault completion/context through migration. Nonzero stage requires five trials. A nonnull context requires matching ongoing rival-kind pendingBattle, exact stage/location/enemy identities, region, class and live active creatures. Finales require id==finaleStage<3; rematches require stage==3 and id==region. No redundant completed/reward flags or duplicate battle snapshot.

Freeze source table format `FINALE_STAGES`: `{id,region,pointId:'camp',name,host,lesson,team:[{speciesId,level}]}`. Move existing unchanged RIVALS table into small `campaign.js` and re-export it from world for old callers; this avoids a campaign/world import cycle. Campaign may import data/build/battle, never world/storage/DOM. Enemy UIDs are `finale-<id>-<encounterIndex>-<slot>` or `rematch-<id>-<encounterIndex>-<slot>`; neutral profiles/traits, cosmetic none, zero XP; seed remains `(seed+encounterIndex)>>>0`. Ordinary wild/trial identities/RNG remain unchanged.

Build ABI: `classRank(state,id)`, `classProgress(state,id)` returning `{rank,current,target,requirement}`, and `perksFor(id,rank=1)` returning existing four combat perk fields plus `fiberBonus` and `contractBonus`; none/rank0 has zero benefits. Validate descriptors/arrays without running imported getters. Keep old `unlockedClasses`, traits and synergy API.

Battle ABI adds optional classRank/enemyClassRank to createBattle options and canonical side snapshots. Missing old ranks become 1 for a class and 0 for none. Resolve perks from the approved frozen table, never saved perk objects. Old pending rank 1 stays rank 1 even if migrated history earns more; new fights pin earned rank, never change it midbattle. Pending validation rejects ranks above earned history, invalid class/rank combinations and nonneutral opponent builds; normal old RNG/effects/resources must replay exactly.

World ABI adds `challengeFor(state,context)` (validated immutable descriptor, ready/current location checked) and `settleChallenge(state,endedBattle)` (copied validated next state; requires current pending context, canonical opponent/party identity and valid won/lost result; clear pending, copy party resources, award/advance once, mark evolution history, recover on loss, increment encounter once). Controller must call settlement BEFORE mutating the state roster to ended resources, so the preceding pending snapshot remains valid. Already settled context cannot pay again. Normal trial/wild settlement remains unchanged.

At camps expose available finale metadata without replacing camp type or recovery. After completion expose beaten regional rival markers as rematches at their original positions, retaining `type:'rival'` plus `challenge:{kind:'rematch',id:region}` and explicit rematch labels so the current view ABI stays intact. Controller services supply explicit lesson/rematch selection; renderer reuses existing rival marker/model conventions where needed. One renderer/canvas/RAF; no view callback awards anything.
