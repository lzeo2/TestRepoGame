# Jankolock 3D model wishlist

World/orchestrator owns the model queue, approved concepts, generation and
asset import. **No Blender.** This index currently records the hero team's
contribution only; it is not a complete world-model plan or asset approval.

Requests and their external/operator-run ownership are unchanged. No wishlist
models are commissioned or built locally here, and no Blender/bpy/sculpt work is
permitted. These scores describe the already-delivered code-generated fallbacks,
not acceptance of the requested external art: 1 = bare placeholder, 10 = finished
concept-quality character. Scores are the orchestrator's visual judgment, not a
triangle-count or hardware benchmark.
