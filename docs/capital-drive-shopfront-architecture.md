# Canberra shopfronts

The playable map has 29 named retail sites across eight districts. Each site has a retained OSM point, a public facing unit allocated on an existing facade, and a parody name. In WebGL, the shared frontage renderer draws 28. Lambzhou 1919 on Bunda Street has a dedicated frontage with a visible cook. Five Manuka precincts keep their separate source boundaries and paths. Manuka Terrace has a purpose-built shell. Canberra Centre has three retained shopping-centre footprints and a dedicated Bunda entrance. Macquarie Shops has a separate, ACT-photo-informed treatment for its two registered buildings. Rental forecourts are fictional facilities.

## Rendering and verification

Both shop windows share the existing local sign atlas. Sprites for groceries, books, bakery trays, restaurant booths, takeaway menu boards, boots and general merchandise occupy previously unused margins. Ten frontage forms vary the door offset and leaf count, window sill, bay count, projecting signs, canopy slope and depth. Sign lettering preserves its aspect ratio across narrow tenancies. The material responds to scene lighting. Overlapping transparent panes would add overdraw, so the displays use opaque colour and small baked reflections.

Two meshes hold the shared storefronts. Their positions and UVs never change. When the player crosses the 180-metre visibility boundary, only the active index ranges upload. No distant facade triangles are submitted. The architecture uses the existing image atlas and has no external requests. The Manuka and Civic architecture retains its existing distance culling.

Run these three checks from the repository root.

```sh
node scripts/test_capital_storefronts.mjs
node scripts/test_capital_shopping.mjs
node scripts/test_capital_civic.mjs
```

The tests check every named facade against its assigned width, terrain and approach direction. They compare the submitted draw indices with the expected visible sites and verify that geometry buffers stay static across districts. Precinct tests check the source buildings, clear paths, triangle budgets, existing bridge clearances and disposal.

## Franklin Street paving and setup cost

Franklin Street now has **137 paved threshold sections** between the mapped
shopfronts and their estimated public approaches. Each section follows the
terrain and is checked against source road widths and building polygons.
The five precincts retain 1,607 mapped path sections and 509 other apron
sections. Together they use two draws and 6,440 triangles.

The precinct renderer previously built a temporary clearance index across all
42,406 buildings and 27,417 roads in the composed map. It now clips the index
to its sampled area, including long shapes that enter from outside. Only 81
road cells and 91 building cells are populated. In three sequential Node runs
per version on the shared cloud host, median setup for this renderer fell from
4,207 ms to 1,245 ms. The median heap change during setup fell from 132.4 MB
to 29.4 MB. These are module construction timings. Full startup and frame rate
depend on other game systems, browser caching and the device.
